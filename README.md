## 📖 About the Project

This portfolio website serves as my personal digital portfolio, showcasing my technical skills, software development projects, education, certifications, and achievements.

The primary goal of this project is to provide recruiters, developers, and collaborators with an organized overview of my work while demonstrating my frontend development skills using modern web technologies.

The website is fully responsive and optimized for desktop, tablet, and mobile devices.

## 🎯 Why I Built This

I wanted to create a professional online presence where recruiters and developers could easily explore my work.

Instead of sharing multiple project links separately, this portfolio brings everything together in one place, including my projects, skills, education, resume, and contact information.

## 🏗 Project Architecture

The project follows a modular structure built with React, TypeScript, and Vite.

```text
PORTFOLIOPROJECT/
│
├── public/                 # Static assets served directly
├── screenshots/            # Images used in README documentation
├── src/                    # Application source code
│
├── .gitignore              # Git ignore rules
├── eslint.config.js        # ESLint configuration
├── index.html              # Root HTML file
├── package.json            # Project metadata & dependencies
├── package-lock.json       # Dependency lock file
├── README.md               # Project documentation
├── tailwind.config.js      # Tailwind CSS configuration
├── tsconfig.app.json       # TypeScript configuration (App)
├── tsconfig.json           # Base TypeScript configuration
├── tsconfig.node.json      # TypeScript configuration (Node)
└── vite.config.ts          # Vite configuration
```

### Architecture Highlights

- Component-based React application
- Built using TypeScript for type safety
- Fast development with Vite
- Utility-first styling using Tailwind CSS
- Separate folders for source code, static assets, and documentation
